# Stock Analyzer
Kleines Python-Kommandozeilenprogramm zur Analyse von Aktienkursen über Yahoo Finance. Es zeigt Unternehmens- und Kursdaten und berechnet wahlweise RSI, MACD oder Bollinger Bänder.

## Installation
Im Projektordner die Abhängigkeiten installieren:
```bash
python3 -m pip install -r requirements.txt
```
## Start
```bash
python3 stock_analyser.py
```
Anschließend ein Tickersymbol (zum Beispiel `AAPL`), einen Zeitraum (zum Beispiel `1y` oder `3mo`) und den gewünschten Indikator eingeben.
Die Ausgaben sind technische Kennzahlen und keine Anlageberatung.
